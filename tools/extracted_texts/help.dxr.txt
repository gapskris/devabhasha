Welcome to Help
Quick Install
1. Load one of The Wonder that is Sanskrit CD-ROMs in your CD-ROM drive. The installation screen will appear in 10-30 seconds.
2. Click on the 'Install
button to load Ligos Indeo 5 video compression software. Follow the onscreen instructions of the installation wizard to install the software. This will take 50-100 seconds approx.
Note: This installation will only be required the first time you run the CD. You need not repeat this procedure every time you run this CD.
3. Ensure that your desktop screen resolution is 800 X 600 pixels. Click on the 'Next' button to run the CD.
System Requirements
To run The Wonder that is Sanskrit CDs, your PC must meet the following minimum requirements:
· Windows 95/98 Multimedia PC with speakers
· Celeron 400MHz or equivalent processor
· 64MB RAM recommended
· 800 X 600 screen resolution
· 48X CD-ROM drive recommended
Installation Procedure in Detail
1. To run the CDs, insert one of The Wonder that is Sanskrit CDs into your CD-ROM drive. If the AutoRun option is enabled on your PC, the installation screen will appear in 10-30 seconds. To learn how to enable the AutoRun option, please refer to Windows Help or go through the section on
Enabling the AutoRun Option
below. The CDs can also be launched by using either the Run command or through Windows Explorer (details below.)
2. The Wonder that is Sanskrit CDs contain video clips. To view these, you require Ligos Indeo 5 video compression software. The installation screen contains an option to install this software. (We recommend that you install this software before proceeding with the CD.)
To install the video compression software, click on the Install button. A wizard will appear which will guide you through the steps for installation. This will take 50-100 seconds approx.
Note: This installation is required only the first time you run the CDs. You need not repeat this procedure to run these CDs every time.
3. Click on the Next button to run the CD.
Launching the CDs with the Run command
1. Insert one of The Wonder that is Sanskrit CDs in your CD-ROM drive.
2. Click on Start on the Windows toolbar and then on Run.
8E8,3. In the Open field type the name of executable file (start.exe) along with path (d:\, e:\) of your CD drive. For example, if the CD-ROM drive in your PC is E: you would have to type e:\start.exe
4. Click on the OK button. This will launch the installation screen.
5. Follow the instructions given above for the rest of the installation process.
Launching the CDs from Windows Explorer
1. Insert one of The Wonder that is Sanskrit CDs in your CD-ROM drive.
2. Go to Windows Explorer and click on your CD-ROM drive to view its contents.
3. Double-click on the start.exe file in the root directory of the CD.
4. This will launch the CD.
5. Follow the instructions given above for the rest of the installation process.
You can also launch the CDs by double clicking on My Computer/CD-ROM drive/start.exe.
Enabling the AutoRun Option
To make CDs play automatically when inserted in the CD drive, the steps are as follows:
- Click Start/Settings/Control Panel. Then click on the System icon.
- Click the Device Manager tab.
- Click the plus sign next to CD-ROM, right-click on the installed CD drive you want to use, and then - Click Properties.
- Click the Settings tab.
- Select the Auto insert notification check box.
Navigation Help
-  Each screen in The Wonder that is Sanskrit CD-ROMs has a navigation bar at the bottom. The Home or main screen contains links to all sections of the CDs. You need to click on a section to view it.
-  You can return to the Home or main screen from any section by clicking on the Home button.
-  The Previous and Next buttons help you navigate within a section by taking you backwards or forward.
- Most sections have a print icon on the first page, which enables you to print the text in that section.Clicking the print icon throws up a dialogue box that enables you to choose the number of pages, number of copies etc. (Note: The number of pages in the dialogue box may not correspond with the total number of pages that appears onscreen in the section.)
- Links within sections let you run video, audio clips, animation sequences, or display information. You can identify a link or clickable section by the change in appearance of the mouse pointer (cursor) from an arrow to a hand when you move the mouse over the text or icon.

- To listen to audio clips click on the audio icon.
- To skip a video clip or animation click on the Skip button.
- To stop the audio click on the Stop icon.
- To close a screen that pops up click on the X button in the right corner of the pop-up.
- To exit the CDs click the X [Exit] button on the navigation bar.
Troubleshooting
CD Autostart Problems
The Wonder that is Sanskrit CDs will launch automatically if the AutoRun option is enabled on your PC. If the CDs don't launch automatically, you can select and run the start.exe file in the root directory of CDs using the Run command or through Windows Explorer. To learn how to enable AutoRun on your PC, please refer to
Enabling the AutoRun Option
in the text above.
Audio Problems
If you are experiencing problems with the audio or can
t hear any audio from the CDs, please check your sound card and audio connections, volume level, and the power connection of your speakers. Incompatibility between the CDs with your sound card could also result in some problems in the audio.
Video Problems
If you experience a problem with the video on the CDs, please check if you have installed the Indeo compression software bundled on these CDs. The installation screen contains an option to install the Indeo Software for video compression. To install this software, please refer to the Help section above.
If you are experiencing jerky video etc. please check if your PC meets the recommended system requirements for the CDs and upgrade your PC accordingly.
Also, please ensure that the video resolution in Windows is set to 800 by 600 pixels and color to High Color (16-bit).
Font Problems
The only user system dependent font used in these CDs is Arial. If Arial is not installed on your PC, you may experience some formatting problems with the text. Please install the Arial font to correct this problem.
Print Problems
If you experience problems with printable text on the CDs, we recommend that you install the correct driver for your printer on your PC. For a standalone PC this can be done through the Add Printer option in the Settings menu under Start. If the printer is on a network, then you will need to check the network communication and install the network printer on your PC.
E-mail/Website Link Problems
The CDs contain e-mail addresses and links to websites. If you are unable to launch your e-mail program to open a new message window after clicking on an e-mail address link, please configure your default e-mail program properly. Similarly, you need to have a browser program installed and be connected to the Internet to be able to go to a website from the CDs.
